# S4 id table: Slice10OnlyWhatTheTeamStillKeepsTest and Slice08NothingToShowTest

Host ids are in `Lighthouse.Backend.Tests.API.Integration.PercentilesOverTime.Slice10OnlyWhatTheTeamStillKeepsTest` and `...Slice08NothingToShowTest`.
Unit ids are in `...Modules.FlowMetrics.Application` (`RetentionEdgeTest`, `OverTimeFillTargetTest`, `PercentileSnapshotWriterTest`, `ReconstructionMemoTest`), `...Adapters.Background.OverTimeHistoryFillerTest` and `...Application.Policies.ProcessBehaviorRecordingHandlerTests`.
Each break is applied to the production line in the working tree, the unit classes are run, and the line is put back (`s4-break-evidence.txt`, run by `s4_breaks.py`; the break ids below are the ids in that file).
Neither class asserts a route, status, JSON name or setting that a row staying elsewhere in the family does not already show, so both classes leave the host and their guard-list lines go.

A removed host row runs the whole path, so each row lists every loop, gate and rule its path walks, not only the one its title names.

Breaks: A1 filler works out days before the first supported day. A2 filler works out days for a team that never finished anything. A3 filler works out days after the last refresh. A4 days stepped over spend the pass allowance. B1 to B4 the fill target no longer wraps the team's percentile families, the portfolio's percentile families, the team's limit families or the portfolio's limit families in the retention guard. B5 and B6 the fill target for a team or a portfolio starts its history before the edge. C1 a window starting on the edge is refused. C2 limits are judged on the window end. C3 limits judge a pinned stretch only when it starts after the window. C4 the edge is drawn a day late. C5 the first day is the oldest finished day even past the edge. C6 an owner that keeps work for ever gets an edge. C7 an owner with nothing finished gets a first day. D1 the window a day reads starts a day early. E1 the span of a team's limits window is one day too long. E2 the window a limits day reads starts a day early. E3 a team's last refresh is read as a UTC day. E4 the pass cap is 1 day.
