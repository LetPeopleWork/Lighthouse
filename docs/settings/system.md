# System

*Settings › System* holds what it takes to run this Lighthouse server.

| Tab | What it holds | Who sees it |
|-----|---------------|-------------|
| **Connections** | The connections to your Work Tracking Systems: [Work Tracking Systems](worktrackingsystems.html) | System Administrators |
| **Database** | Backup, restore and clear: [Database Management](databasemanagement.html) | System Administrators |
| **Encryption** | The key that encrypts stored credentials: [Secret Encryption Key](encryption.html) | System Administrators |
| **Demo Data** | Sample scenarios to explore or train with: [Demo Data](demodata.html) | System Administrators |
| **Usage Data** | Whether this instance may send usage data: [Usage Data](usagedata.html) | System Administrators |
| **System Info**, **Logs**, **Refresh History** | Versions, the log and its level, what refreshed when: [System Info](systeminfo.html) | Everyone |
| **License** | The license status, with import and clear for System Administrators: [Licensing](../licensing/licensing.html#license-information-in-lighthouse) | Everyone |
