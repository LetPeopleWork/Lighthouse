# Access

*Settings › Access* holds who may do what.

| Tab | What it holds | Who sees it |
|-----|---------------|-------------|
| **System-wide access** | System Admins, SSO group rules and the *Everyone signed in* switch | System Administrators, once [RBAC](rbac.html) is enabled |
| **API Keys** | Personal keys for the CLI, MCP servers and other automation | Everyone |

See [Role-Based Access Control](rbac.html) and [API Keys](apikeys.html).
